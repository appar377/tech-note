MT5用にUbuntu系Linuxを選ぶなら、最初に決めたいのは「画面をどう確認するか」と「選んだ構成をいつまで保守するか」です。デスクトップの名前だけで、MT5の互換性や常駐時の安定性を決めることはできません。

MetaQuotesのLinux導入ガイドはWineを利用する手順を案内しています。この案内と、各Ubuntu flavorで同じ結果になるかという確認は分けて扱います。[MetaTrader 5のLinux導入ガイド](https://www.metatrader5.com/en/terminal/help/start_advanced/install_linux)

この記事は候補を絞るための比較です。各OSへMT5を導入して測った使用メモリ、速度、安定性の順位は示していません。

## デスクトップが違うと、何を選び直すことになりますか

Ubuntuのflavorは、デスクトップや既定のアプリ、設定などを組み合わせた選択肢です。LubuntuはLXQt、XubuntuはXfce、KubuntuはKDE Plasmaを提供します。[Ubuntu flavors](https://ubuntu.com/desktop/flavors)

表の最後の列は、選定時に答えておきたい問いです。MT5での動作評価ではありません。

| 候補 | 主に使う操作環境 | 選定前に確かめること |
|---|---|---|
| Ubuntu Desktop | GNOME。24.04 LTSではGNOME 46 | 利用するリリースのセッションと、必要な画面操作を扱えるか |
| Lubuntu | LXQt | 必要な画面設定や遠隔確認の方法を用意できるか |
| Xubuntu | Xfce | 日常の確認作業を、このデスクトップで説明・再現できるか |
| Kubuntu | KDE Plasma | 利用するリリースでの表示・拡大率・入力の設定を把握できるか |
| Ubuntu Serverにデスクトップを追加しない構成 | シェル中心。GUI表示の経路は別途設計 | Wineが使う表示先と、問題発生時に画面を確認する方法を用意できるか |

Ubuntu Desktop 24.04のデスクトップ版と既定アプリの構成は、[24.04 LTSリリースノート](https://discourse.ubuntu.com/t/ubuntu-24-04-lts-noble-numbat-release-notes/39890)で確認できます。Ubuntu Serverは必要に応じてソフトウェアを追加していく構成として説明されており、ここでは「デスクトップを追加しない」という選択を比較対象にしています。[Ubuntu Serverの基本導入](https://ubuntu.com/server/docs/tutorial/basic-installation/)

GUIが必要なら、設定や障害時の確認を自分で説明できるデスクトップを候補にできます。一方、デスクトップを置かない構成を選ぶなら、表示先を誰が起動し、どう確認するかまで選定条件に含めます。

## 「Ubuntuが入る」と「必要なバイナリが動く」は同じですか

Ubuntuが対応するCPUアーキテクチャと、MT5・Wine・Pythonの組み合わせが必要とする条件は、別々に確認します。たとえばUbuntu Serverにはamd64やarm64などの選択肢がありますが、それだけで同じWindows向け配布物を使えるとは判断できません。[Ubuntu Serverの対応アーキテクチャ](https://ubuntu.com/server/docs/tutorial/basic-installation/)

対象のUbuntuで、dpkgが扱う基本のパッケージアーキテクチャを読むコマンドは次です。これは読者向けの参考例であり、この記事では実行していません。

```bash file=reader-only/package-architecture.sh
#!/usr/bin/env bash
set -eu

# 読者が対象の Ubuntu で使う参考例。合成入力のチェックからは実行しません。
dpkg --print-architecture
```

`dpkg --print-architecture`はパッケージのアーキテクチャを表示する操作です。CPU全体の機能やWineの互換性を診断するコマンドではありません。[dpkgのマニュアル](https://manpages.debian.org/bookworm/dpkg/dpkg.1.en.html)

Python連携まで使う予定なら、OS選定の時点で配布物も確認します。例としてMetaTrader5 5.0.6231には、CPython 3.12・Windows x86-64向けの`cp312-cp312-win_amd64`というwheelがあります。この配布条件を、LinuxのPythonにもそのまま適用することはできません。[5.0.6231の配布ファイル](https://pypi.org/project/metatrader5/5.0.6231/#files)

ここで確認するのは配布物との条件の一致です。特定のCPU上でWineとMT5を組み合わせた実動作は、さらに別の確認として残ります。

## LTSなら、すべて同じ期間保守されますか

Ubuntu本体の保守期間と、flavorが公表する保守期間は、同じ表だけでは判断できません。また、外部から追加するWineなどまでUbuntuの期間で一括して扱わないようにします。

違いを読む例として24.04 LTSを見ると、Ubuntuの標準セキュリティ保守は2029年5月までで、LTSの標準保守の対象はMainのパッケージです。一方、Lubuntu 24.04 LTSは2027年4月までの3年間を公表しています。これは24.04の保守条件の比較であり、24.04を最新の候補やMT5で検証済みの版として勧めるものではありません。[Ubuntuのリリースと保守期間](https://ubuntu.com/about/release-cycle)、[Lubuntu 24.04.1の告知](https://lubuntu.me/noble-1-released/)

候補のリリースごとに、少なくともOSの期限、flavorの期限、追加パッケージの提供元を確認します。更新後にGUI表示とPython連携を再確認できるかも、保守を続けるための条件になります。

## 軽さを比べたいときは、何をそろえますか

デスクトップの一般的な紹介から、そのままMT5環境の使用メモリの順位を作ることはできません。比較するなら、割り当てるCPU・メモリ、OSとWineの版、MT5の条件、表示解像度、遠隔表示の方式を記録します。

さらに、測る時点を「デスクトップへログインした直後」「対象アプリを表示している間」などに分けます。OSだけで消費する量と、同じ作業を載せたときの量を混ぜると、flavorを変えた効果を読み取りにくくなるためです。

この記事ではこの測定を行っていません。必要な操作を実現できる候補が複数残ったときに、実際の条件をそろえて比較するための観点です。

## GUIありとServerのどちらから始めますか

画面上の状態を人が確認する必要があり、その確認方法をすぐ説明できるなら、使い慣れたGUI環境を候補にできます。その後に必ずUbuntu Serverへ移す、という前提を置く必要はありません。

デスクトップへのログインを前提にしない構成が必要なら、Ubuntu Serverを含む候補で表示先と復旧方法を設計します。GUIを減らすこと自体は、アプリの自動復旧を保証しません。

候補を選んだら、[GUI確認で観測すること](/tech-note/articles/linux/mt5-ubuntu/02-gui-flavors-validation/)へ進みます。デスクトップを使わない構成の検討は、[headless設計](/tech-note/articles/linux/mt5-ubuntu/03-ubuntu-server-headless-design/)で扱います。
