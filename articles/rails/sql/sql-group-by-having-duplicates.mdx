## 概要

メーカー名、発売日、車種IDなど、同じ値の組み合わせを持つレコードを調べる必要があった。Rubyで全件読み込むのではなく、DBの集約機能で候補を絞る。

重複検出は`GROUP BY`で同じキーをまとめ、`HAVING COUNT(*) &gt; 1`で複数件のグループだけを残す。検出後は実レコード取得と再発防止の一意制約まで設計する。

## この記事で学べること

- 単一カラムの重複
- 複合キーの重複
- `WHERE`と`HAVING`の役割差
- NULLを含む場合のグルーピング
- 重複グループだけでなく実レコードを取るCTE/JOIN
- どのレコードを残すかの決定

## 実装コード例

```sql
SELECT email, COUNT(*) AS count
FROM users
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY count DESC;
```

```ruby
class DuplicateEmailReport
  def call
    User.select("email, COUNT(*) AS count")
      .group(:email)
      .having("COUNT(*) > 1")
      .order("count DESC")
  end
end
```

## 内部動作

Railsの抽象化は、Rubyオブジェクト、Active Record、SQL、DBトランザクションの上に成り立っています。重要なのは、Railsのメソッド呼び出しがそのままDBの履歴や外部サービスの状態になるわけではない、という点です。

- `COUNT(*)`と`COUNT(column)`はNULLの扱いが異なる
- DBごとのNULL一意制約挙動を確認する
